


# 🧬 Livestock Biosecurity Screening Tool

A computational tool for screening DNA sequences against common zoonotic pathogen indicators in livestock supply chains.

## 📋 What It Does
Scans DNA sequences for motifs associated with regulated livestock diseases (Brucella, TB, Newcastle, etc.) using 6-frame translation.

## 🔧 Tech Stack
- Python
- Biopython
- Streamlit
